Cara Cara Deploy Website Ini ke GitHub Pages (github.io)

Kamu dapat langsung meng-host website kalkulator ini secara gratis menggunakan GitHub Pages. Ikuti langkah simpel berikut:

1

Buat Repository Baru

Buka GitHub, buat repository baru dengan nama misal kalkulator-anuitas. Biarkan Public.

2

Upload File HTML

Upload atau buat file baru bernama index.html di repository tersebut, lalu paste seluruh kode dalam file ini.

3

Aktifkan GitHub Pages

Buka menu Settings > Pages di repository-mu. Pilih branch main / master dan klik Save. Website kamu live!
